# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - 2026-08-19

Private preview.

- Cloned Omarchy's built-in Display widget into a user-owned plugin.
- Preserved brightness, text-size, scale, and connected-display controls.
- Added live hyprmoncfg service and profile status over IPC.
- Added automatic switching and layout-editor actions.
- Consolidated the two Display bar entries into one keyboard-accessible panel.
